Privacy policy

OpenBot Mail Verification is a personal desktop utility operated by the owner of the connected Gmail account.

Information accessed and purpose

With your consent, the utility uses Gmail read-only access to list recent message identifiers and read candidate messages, including their sender, subject, receipt time and message content. It selects account verification messages using the requested sign-in time and the supported service's sender and verification endpoint. It processes a verification code or device approval link only to complete a sign-in you requested.

Selection is bounded to at most 20 distinct messages for a challenge. Read-only authorization applies to the Gmail account; the application's filters narrow what it retrieves, rather than narrowing Google's account-level permission. The utility does not send, delete, label or mark email as read.

Storage and protection

OAuth client configuration and the refresh token are stored in local files restricted to the operating-system user. Access tokens and normally processed message data remain in process memory. Explicit investigation snapshots may contain message data and are stored only in private local files. Metadata receipts contain statuses and counts, not email bodies, codes or approval links.

The public website does not receive or store email messages, verification codes, approval links or OAuth tokens.

Sharing and use limits

The utility communicates with Google's OAuth and Gmail APIs over HTTPS. When device approval is explicitly enabled, it sends the selected verification request directly to the supported account service's exact verification endpoint. It does not sell email data, use it for advertising, share it with analytics providers, or use it to train AI models.

OpenBot Mail Verification's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

You control this local installation. Stop the utility and delete its private OAuth configuration to remove its locally stored authorization. Delete any locally collected message snapshots and receipts if you no longer need them. Revoke the application's access through your Google Account connections to invalidate its authorization at Google. Deleting a local token file alone does not revoke Google's authorization.

Website hosting and contact

This website has no analytics scripts, tracking pixels, contact forms or application cookies. GitHub Pages hosts it and may process ordinary web request information under GitHub's privacy statement.

For questions, contact the maintainer through the website repository. Do not post email content, tokens, verification codes or private account information in a public issue.
