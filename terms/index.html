Terms of use

This utility is provided for the owner's personal account verification on a locally managed computer.

Authorized use

Connect only a Gmail account you own or are authorized to operate. Use verification messages only for sign-ins you have requested and are authorized to complete. Device approval must be explicitly enabled for that flow. The utility does not grant permission to access another person's account or override a service's security requirements.

Local installation and account control

You control the computer, local configuration and authorization. Keep the private token files and any collected message snapshots protected. You can stop the utility, delete local data and revoke Google access at any time. Data handling is described in the privacy policy.

Availability

Google or the account service may require renewed sign-in, revoke authorization, or change an API. The utility cannot guarantee uninterrupted verification and does not bypass additional security challenges. This website provides information only; it does not offer hosted mailbox access or a public account verification service.

Support

Contact the maintainer through the website repository. Public support requests must not contain email messages, credentials, OAuth tokens or verification material.
